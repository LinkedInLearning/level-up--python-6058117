## 课程说明
本资源库为课程中的每个视频提供了对应的分支。你可以使用 GitHub 中的分支切换菜单选择特定分支，查看该视频对应的代码；也可以在网址末尾添加 /tree/分支名来访问对应分支。
## 分支说明
这些分支与课程中的视频一一对应。命名格式为 CHAPTER#_MOVIE#。例如，名为 02_03 的分支表示第 2 章的第 3 个视频。

有些分支同时提供了“开始”和“结束”两种状态，分别用字母 b（beginning）和 e（end）标识。

b 分支表示该视频开始时的代码状态。

e 分支表示该视频结束时的代码状态。

main 分支保存课程结束时的完整代码。

当你在本地对文件做了修改之后再切换分支，可能会看到如下错误信息：

    error: Your local changes to the following files would be overwritten by checkout:
    Please commit your changes or stash them before you switch branches.
    Aborting

要解决这个问题，请执行以下命令:
	
    Add changes to git using this command: git add .
	Commit changes using this command: git commit -m "some message"
